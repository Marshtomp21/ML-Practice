# XAI01-01 梯度类归因方法：实验结果汇总


## 1. 实验范围与评价口径

| 项目 | 设置 |
|---|---|
| 已完成正式归因评价的数据集 | ImageNet验证子集，100张 |
| 图片筛选 | 从已有500张候选预测记录中，保留ResNet-50 Top-1分类正确样本；seed=42打乱后，每个预测类别选1张，直至100张。不是全验证集无条件随机抽样，也未按VGG13共同正确筛选 |
| 模型 | torchvision ResNet-50，ResNet50_Weights.IMAGENET1K_V2，eval模式 |
| 本组方法 | Saliency、Integrated Gradients（主配置IG-blur）、Expected Gradients、Grad-CAM |
| 正式评价输入 | RGB；使用该官方权重的weights.transforms()预处理，输出224×224；均值[0.485,0.456,0.406]，标准差[0.229,0.224,0.225] |
| 固定目标类别 | 清单中的target_class_index，为原图预测类别；所选原图全部预测正确，因此也等于真实类别。加噪后仍保持原图目标，不随预测变化重选 |
| 忠实性模型得分 | 目标类别的Softmax概率，而非原始logit |
| 评价遮蔽基线 | 预处理后的RGB图进行PIL GaussianBlur(radius=15)，再归一化；Insertion从模糊图恢复像素，Deletion把原图像素替换成模糊像素 |
| Insertion / Deletion | 根据224×224归因图逐像素降序排序；比例0、0.1、…、1，共10个区间、11个采样点；梯形积分计算概率AUC；不使用SLIC区域划分 |
| 输入稳定性 | 原始RGB图在[0,1]空间加入高斯噪声，std=0.01，固定随机生成器seed=42；截断至[0,1]并保存为8位PNG，每张原图对应1张固定噪声图 |
| 稳定性指标 | 原图/噪声图归因数组展平后的Spearman相关系数；各自90%分位阈值以上区域的交并比Top-10% IoU。阈值并列时区域可能超过10% |
| 主表汇总 | 每种方法100张图的算术均值；不是中位数 |
| 计时 | 原图归因结果的CUDA计时；下表统一换算为秒/图。不同组员设备和实现环境未完全统一，耗时只作描述性参考 |
| 正式评价环境 | Python 3.11.16、PyTorch 2.6.0+cu124、torchvision 0.21.0+cu124、CUDA 12.4；评价主机RTX 4060 Laptop GPU。该环境不代表全部归因结果生成环境 |

指标方向：Insertion AUC越高越好；Deletion AUC越低越好；Spearman和Top-10% IoU越高越好；耗时越低越好。

统一评价读取的归因字段分别为：Saliency的attribution、IG的absolute_map、EG的attribution_norm、Grad-CAM的gradcam__layer4.2。它们是数值数组，不是从彩色叠加图反推的数据。跨组接入时还需核对符号与通道聚合规则。

主要方法参数：IG-blur采用模糊基线radius=15、512步自适应积分、internal_batch_size=16；EG记录为10个参考基线、每条路径50步、seed=42，参考分布为固定种子的N(0,1)高斯；Grad-CAM目标层为ResNet-50的layer4.2。

## 4. IG基线对比补充结果（ImageNet 100张）

四种基线各有100张原图和100张噪声图评价记录，沿用同一批图、同一模型及正式评价规则。以下为均值。

| IG基线 | Insertion概率AUC ↑ | Deletion概率AUC ↓ | Spearman ↑ | Top-10% IoU ↑ | CUDA耗时（秒/图）↓ |
|---|---:|---:|---:|---:|---:|
| black | 0.279196 | 0.142605 | 0.782519 | 0.494997 | 2.361788 |
| blur | **0.368900** | **0.049587** | 0.827804 | 0.525975 | 2.340508 |
| mean | 0.310722 | 0.104488 | 0.795834 | 0.485866 | 2.350821 |
| random | 0.329169 | 0.073252 | **0.917392** | **0.743718** | 2.328974 |

模糊基线在本实验忠实性上最好，随机基线在稳定性上最好。按现有配对检验，blur的两项忠实性显著优于其他三种基线，random的两项稳定性显著优于其他三种基线。基线选择结论来自当前同批图片，不是独立留出集对最优基线的再次验证。

## 5. 配对统计与主要观察

已有统计采用100张图像配对Bootstrap 10,000次、seed=42、95%置信区间；双侧Wilcoxon检验，每指标内6组两两比较采用Holm校正。以下p值为校正后结果。

| IG-blur与Grad-CAM比较 | Holm p | 结论 |
|---|---:|---|
| Insertion概率AUC | 0.672 | 未检出显著差异，不能把IG微小均值优势解释为明确胜出 |
| Deletion概率AUC | 2.6e-14 | IG-blur显著更好 |
| Spearman | 2.34e-17 | Grad-CAM显著更好 |
| Top-10% IoU | 2.34e-17 | Grad-CAM显著更好 |

主要观察：

1. **综合实用选择：Grad-CAM。** 当前稳定性突出、Insertion有竞争力、记录耗时短；效率排序仍有硬件混杂，结论不是跨模型或跨数据集的普遍保证。
2. **忠实性优先：IG-blur。** Deletion显著优于Grad-CAM，但计算成本高；Insertion与Grad-CAM未检出显著差异。
3. **EG：** 当前Deletion和两项稳定性均位于四方法第二，具有一定均衡性，但记录耗时较长。
4. **Saliency：** 记录耗时短，当前两项忠实性和稳定性均落后于其他三种方法。
5. **稳定性与忠实性不能互相替代。** Grad-CAM更稳定不意味着Deletion最好；IG-random更稳定也不意味着其忠实性超过IG-blur。
6. 跨组建议同时报告Grad-CAM与IG-blur，分别代表综合实用和忠实性优先配置。
