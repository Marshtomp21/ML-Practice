# 三个扰动基线：CHNCXR 全样本主设置实验

本轮按 M1 主设置运行全部共同正确样本。

- 完成时间（UTC）：2026-09-10T19:40:58.693600+00:00
- 候选池：662 张；两个模型共同正确：434 张。
- 共同正确样本类别分布：{'0': 177, '1': 257}（0 正常，1 结核阳性）。
- 实际样本：全部 434 张共同正确样本。
- LIME/RISE 种子：[0, 1, 2, 3, 4]；Ablation 为确定性方法，每张图仅运行一次。
- 共 9548 条方法运行记录；LIME/RISE 单次预算 1024，Ablation 为实际区域数 + 1。
- GPU：NVIDIA GeForce RTX 4050 Laptop GPU；批大小 32；每模型预热 3 批。
- 预处理：RGB，PIL 双线性缩放至 224×224，mean/std 均为 0.5；课程 prior 源码提供该推理口径。
- 目标：正确类别原始 logit；遮蔽：归一化输入空间的零；SLIC 在归一化前 RGB 上生成并共享。

## 拟合诊断与使用限制

- resnet50 的 LIME 邻域加权 R²：中位数 0.6337，范围 0.4110–0.7910。该指标仅衡量局部代理拟合。
- vgg13 的 LIME 邻域加权 R²：中位数 0.6353，范围 0.4621–0.9685。该指标仅衡量局部代理拟合。
- 本轮仅 CHNCXR 两个模型，尚未运行 ImageNet、参数扫描、输入噪声稳定性或定位性评价。
- RISE 使用原始 logit 替代概率；其像素图按 SLIC 区域求和参与排序。LIME/Ablation 直接使用区域系数，不额外乘区域面积。
- 本轮不做显著性检验，不将种子重复或种子对当作独立图像样本。
- 单次方法计时受 GPU 温度与系统负载影响；方法执行顺序按图像固定随机打乱。
